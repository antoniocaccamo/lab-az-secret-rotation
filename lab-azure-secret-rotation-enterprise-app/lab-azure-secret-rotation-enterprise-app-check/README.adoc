= func-enterprise-app-secret-check
//:toc:
:sectnums:

For a give list of owners, it collects their Enterprise Apps and checks if Password Credentials are near to expiry or expired and generates related events.

Parameters:
[horizontal]
`ENTERPRISE_APPS_CHECK`:: JSON array containing name of Enterprice App to check  and recipients to send mail, as follow: +
      `[{"applicationId":"254207e6-xxx","recipients":"email.01@example.org"},
       {"applicationId":"a556add5-yyy","recipients":"email.02@example.org"}]`

`ENTERPRISE_APPS_CHECK_EXPIRING_PERIOD` :: days before considering a password near to expiring   (optional, default 30 days)
`EVENT_GRID_ENTERPRISE_APP_ENDPOINT`:: End point url of enterprise app event grid

== Enterprise App Events

The value of events:

* `EnterpriseApp.PasswordCredentialNearExpiry`
* `EnterpriseApp.PasswordCredentialNearExpiryAndCreate`
* `EnterpriseApp.PasswordCredentialExpired`
* `EnterpriseApp.PasswordCredentialExpiredAndCreate`

are not defined by Azure, but they were logically defined in this context.

== Assign roles
[source, bash]
----
# get id for  User Assigned Identity principal
userAssignedIdentity="mi-secret-rotation-enterprise-app-check"
principalId=$(az ad sp list --display-name $userAssignedIdentity  --query "[0].id" -o tsv)

# get id for
# graphId=$(az ad sp list --query "[?appDisplayName=='Microsoft Graph'].id | [0]" -o tsv --all)
graphId=$(az ad sp list --display-name 'Microsoft Graph' --query  "[0].id" -o tsv --all)

# retrieve id for require Microsoft Graph permissions
appRoles=( "User.Read.All" "Application.Read.All")
allowedMemberTypes=Application

# appRole loop
for appRole in "${appRoles[@]}"; do
  echo "assign \"$appRole\" to user assigned managed identity \"$userAssignedIdentity\""
  appRoleId=$(az ad sp list --display-name "Microsoft Graph" --query "[0].appRoles[?value=='$appRole' && contains(allowedMemberTypes, '$allowedMemberTypes')].id" -o tsv)
  echo "{ \"principalId\" : \"$principalId\", \"resourceId\"  : \"$graphId\", \"appRoleId\"   : \"$appRoleId\" }" > assign."$appRole".json
  az rest --method post \
    --uri https://graph.microsoft.com/v1.0/servicePrincipals/$principalId/appRoleAssignments \
    --body @assign.$appRole.json \
    --headers Content-Type=application/json
done
----
